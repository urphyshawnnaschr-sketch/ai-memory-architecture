# 记忆体检清单模板

> 每周或每两周跑一次。逐项检查，标记完成。
> 就像体检报告——不是每项都有问题，但每项都该看一眼。

---

## 体检日期：YYYY-MM-DD

### 一、核心记忆

- [ ] 容量是否超过 50%？ → 超了就瘦身
- [ ] 有没有过时的条目？ → 删或更新
- [ ] 有没有只在特定领域用的信息？ → 搬到域外挂
- [ ] 有没有重复的条目？ → 合并

### 二、工作日志

- [ ] "当前活跃"里的任务还准确吗？ → 更新状态
- [ ] 有没有做完了但忘了移到"已完成"的？ → 移过去
- [ ] 进度描述还准确吗？ → 更新

### 三、会话书签

- [ ] 有超过 20 行的书签？ → 精简
- [ ] 有重复工作日志内容的书签？ → 改成指针
- [ ] 有过时的书签？ → 删除或归档

### 四、触发词路由表

- [ ] 有没有新领域该加触发词？ → 加上
- [ ] 有没有不再活跃的域？ → 考虑移除
- [ ] 外挂文件路径还正确吗？ → 验证

### 五、利用率（可选）

- [ ] 跑一次利用率统计 → 标记冷数据
- [ ] 冷数据是否该删/该搬？ → 处理

---

## 体检结论

- **健康度：** 🟢 良好 / 🟡 需要整理 / 🔴 急需瘦身
- **本次操作：** [简述做了什么]
- **下次体检：** YYYY-MM-DD

---

> **使用提示：**
> - 不用每次都做"五、利用率"，那个月度做一次就够
> - 检查完在对应条目打勾，留个记录
> - 如果连续两次都是 🟢，可以改成月度体检

---

> **💡 升级提示：自动化体检**
>
> 如果你用的 AI 工具支持跑脚本（Claude Code、Cursor 等），可以把这个清单升级成自动化脚本——一句话触发，2 秒出结果，不再需要手动逐项检查。
>
> 详见 [进阶七：自动化体检](../docs/04-advanced.md#进阶七自动化体检记忆管家)

## 示例（填好的样子）

```markdown
## 体检日期：2025-04-13

### 一、核心记忆
- [x] 容量是否超过 50%？ → 当前 41%，OK
- [x] 有没有过时的条目？ → 删了一条旧的环境路径
- [x] 有没有只在特定领域用的？ → "专栏排期"搬到 writing 外挂
- [x] 有没有重复的条目？ → 无

### 体检结论
- **健康度：** 🟢 良好
- **本次操作：** 删 1 条过时 + 搬 1 条到域外挂
- **下次体检：** 2025-04-27
```
