# 暗号路由表模板

> 当用户说出暗号时，AI 自动加载对应的外挂记忆文件——就像谍战片里的接头暗号。
> 核心记忆里只需要一行：`📋 暗号表: <本文件路径>`

---

## 路由表

| 触发词 | 域 | 外挂文件路径 | 说明 |
|--------|-----|-------------|------|
| 例：写作 | writing | memory/writing/worklog.md | 小说/博客写作 |
| 例：项目 | project | memory/project/worklog.md | 工作项目管理 |
| 例：社群 | community | memory/community/worklog.md | 社群运营 |

> 按需增删行。每加一个域，只改这张表，核心记忆不用动。

---

## 暗号路由链路

```
核心记忆（一行指针）
  → 本文件（暗号 → 外挂路径）
    → 各域 worklog（按需加载）
      → 子目录/子文件（深度内容）
```

---

## 使用规则

1. **用户消息包含暗号** → AI 自动读取对应外挂文件
2. **没匹配到任何暗号** → 不加载任何外挂，正常对话
3. **一条消息匹配多个暗号** → 按表中顺序依次加载
4. **新增域** → 在表里加一行，创建对应 worklog 文件，完事

---

## 核心记忆里怎么写

只需要一行：

```
📋 暗号表: ~/.your-ai/memory/trigger-table.md
```

不要把每个域的路径都写进核心记忆。那是这张表的工作。

---

## 示例（填好的样子）

```markdown
## 暗号表

| 暗号 |
|--------|-----|-------------|------|
| 专栏 | writing | memory/writing/worklog.md | 科技评测专栏 |
| 读书 | reading | memory/reading/worklog.md | 读书笔记整理 |
| 社群 | community | memory/community/worklog.md | 微信社群运营 |
```
