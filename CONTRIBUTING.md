# Contributing

Thanks for helping improve AI Memory Architecture.

This repository is a methodology and template project. Contributions are most useful when they make the method clearer, more portable, or easier to validate in real workflows.

## Good contribution areas

- Fix ambiguous or inconsistent terminology.
- Improve the Chinese or English documentation.
- Add a tool-specific adaptation without making the core method depend on that tool.
- Add a reproducible example of a memory/context failure mode and the method used to mitigate it.
- Improve one of the templates while preserving its role in the architecture.
- Add evidence from real use, including cases where the method did not work as expected.

## Scope guardrail

Please do not expand this repository into a general-purpose agent platform, multi-agent orchestration framework, enterprise AI operating system, or proprietary memory service. Those can be interesting projects, but they are outside this repository's scope.

## Before opening a pull request

1. Explain the problem your change addresses.
2. State which principle, document, or template it affects.
3. Avoid duplicating authoritative progress or state in multiple files.
4. Keep examples free of credentials, private customer information, personal conversation history, and other sensitive data.
5. Prefer small changes that can be reviewed independently.

## Suggested pull request format

- **Problem:** What is confusing, missing, stale, or incorrect?
- **Change:** What did you change?
- **Why:** Why is this consistent with the methodology?
- **Validation:** How did you check that the example/template still works?
- **Scope:** What did you intentionally not change?

## Language

Chinese is currently the most complete documentation language. English contributions are especially welcome. Other translations are welcome when they preserve the meaning of the core concepts rather than translating terminology literally without context.
