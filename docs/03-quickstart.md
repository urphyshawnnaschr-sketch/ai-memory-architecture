# 30 分钟搭起来

[← 返回目录](../README.md) | [上一章](02-principles.md)

> 不需要编程，不需要特殊工具。找到你的档位，跟着 1-2-3 做，30 分钟后你的 AI 就有了结构化的记忆。

---

## 先确认：你的 AI 属于哪一档？

| 档位 | 判断标准 | 代表工具 |
|------|---------|---------|
| 🟢 **满血档** | AI 能直接读写你电脑上的文件 | Cursor / Windsurf / Claude Code / Trae / Hermes Agent |
| 🟡 **半血档** | AI 有内置记忆功能，但你不能完全控制 | ChatGPT Memory / Claude Projects / Gemini Gems |
| 🔴 **手动档** | 每次对话都是全新开始，AI 不记得上次聊了什么 | Kimi / DeepSeek / 豆包 / 通义千问 / 任何纯对话窗口 |

> **不确定？** 问你的 AI："你还记得我上次跟你说了什么吗？"
> - 如果它能准确回忆 → 🟡半血 或 🟢满血
> - 如果它说"我无法获取之前的对话" → 🔴手动

找到了？往下看你那档的步骤。

---

## 🟢 满血档：模板直接用

**适用于：** Cursor / Windsurf / Claude Code / Trae / Hermes Agent 等能读写本地文件的 AI 工具。

### 第 1 步：创建核心记忆文件（5 分钟）

在你的项目文件夹里创建 `MEMORY.md`（或你的工具指定的记忆文件），用 [核心记忆模板](../templates/memory-core.md) 填写：

```markdown
# 核心记忆

## 身份
我叫小王，产品经理。

## 沟通偏好
- 用中文
- 回答简洁，不要废话
- 改文件前先问我

## 暗号路由
- 说"聊写作" → 加载 writing-worklog.md
- 说"聊项目" → 加载 project-worklog.md
```

**关键：只写"每次对话都要用到"的信息。** 某个项目的详细进度、上次聊天的内容——这些不该放在核心记忆里。

各工具的文件位置：

| 工具 | 核心记忆文件 |
|------|------------|
| Claude Code | `MEMORY.md`（项目根目录） |
| Cursor | `.cursorrules` 或 Custom Modes 设置 |
| Windsurf | Memories 功能（可手动编辑） |
| Trae | 项目规则 或 `.trae/rules` |
| Hermes Agent | 自动管理，`memory` 命令写入 |

### 第 2 步：建工作日志 + 暗号路由（10 分钟）

每件你在让 AI 帮忙的事，建一个 [工作日志](../templates/worklog.md)：

```
📁 你的项目/
   ├── MEMORY.md              ← 核心记忆
   ├── writing-worklog.md     ← 写作进度
   ├── project-worklog.md     ← 项目进度
   └── learning-worklog.md    ← 学习进度
```

然后在核心记忆里加上暗号路由（上一步示例已包含）。以后你说"聊写作"，AI 就知道该去读 `writing-worklog.md`。

> 💡 **暗号就像谍战片里的接头暗号**——你说一个词，AI 就知道该切换到哪套记忆。不用的记忆不加载，AI 脑子就不会乱。

### 第 3 步：养成存档习惯（5 分钟）

每次聊完一个阶段，让 AI 打一个书签：

```
存档两步走（顺序不能反）：

第一步：更新工作日志
  "把今天的进展更新到工作日志里"

第二步：打个书签
  - 在聊什么（一句话）
  - 断点（下次从哪接着）
  - 下一步
```

### ✅ 验证：确认搭好了

开一个新的对话窗口，测试三件事：

1. **"你知道我是谁吗？"** → AI 应该能说出你的名字和偏好
2. **说你的暗号**（比如"聊写作"） → AI 应该去读对应的工作日志
3. **试试触碰你的规则**（比如让它改文件） → AI 应该先征求你同意

三条都过？✅ 基础架构搭好了。

## 🟡 半血档：记忆贴进设置

**适用于：** ChatGPT Memory / Claude Projects / Gemini Gems 等有内置记忆但不能读写本地文件的 AI 工具。

### 第 1 步：写一份核心记忆（5 分钟）

用 [核心记忆模板](../templates/memory-core.md)，但要精简——这些工具的记忆空间有限。

**ChatGPT** → Settings → Personalization → Custom Instructions
```
我叫小王，产品经理。中文沟通，回答简洁。改东西前先确认。
目前在做两件事：①写作项目 ②产品规划。
每件事的详细进度我会单独告诉你，这里只记大方向。
```

**Claude Projects** → Project Instructions
```
同上，贴在项目说明里。每个项目可以有自己的 Instructions。
```

**Gemini Gems** → 创建一个 Gem，在描述里写核心记忆。

### 第 2 步：自己维护一份工作日志（10 分钟）

半血档的 AI 没法自己读写文件，所以工作日志你自己维护：

- 用你习惯的笔记工具（备忘录、Notion、飞书文档、甚至一个 txt 文件）
- 每件事一份，格式参考 [工作日志模板](../templates/worklog.md)
- **每次聊完一个阶段，把关键进展手动更新进去**

当你开始新对话时，把相关的工作日志内容贴给 AI：

```
"我们继续聊写作项目。这是目前的进度：
[贴你的工作日志内容]"
```

### 第 3 步：教 AI 提醒你存档（5 分钟）

在 Custom Instructions 里加一句：

```
当我们聊了比较多内容后，提醒我"要不要存个档？"。
存档 = 让我把进度更新到我的笔记里。
```

### ✅ 验证：确认搭好了

1. **开新对话，什么都不说，看 AI 是否知道你是谁** → 应该知道（因为有 Custom Instructions）
2. **贴入工作日志后，问进度** → AI 应该能基于贴入的内容回答
3. **聊一阵子后** → AI 应该提醒你"要不要存个档"

## 🔴 手动档：每次贴记忆简历

**适用于：** Kimi / DeepSeek / 豆包 / 通义千问 / 任何没有持久记忆的 AI。

别灰心——手动档也能用这套方法论，只是多一个"每次贴简历"的步骤。

### 第 1 步：写一份"AI 简历"（5 分钟）

这是你每次开聊时贴给 AI 的第一段话。参考 [核心记忆模板](../templates/memory-core.md)，但要更精简：

```
[贴在每次对话的第一句]

你好，我叫小王，产品经理。
- 用中文，回答简洁
- 我目前在做：①写作项目（第3章进行中）②产品规划（需求评审阶段）
- 改东西前先确认
- 今天我想聊的是：[写作项目]
```

**技巧：把这段话存在手机备忘录 / 电脑便签里，每次复制粘贴。**

### 第 2 步：自己维护进度（10 分钟）

跟半血档一样，自己用笔记工具维护 [工作日志](../templates/worklog.md)。

关键区别：每次开新对话后，你需要把相关进度贴给 AI。

```
第一句：贴 AI 简历
第二句：贴当前话题的工作日志
第三句：说你今天要做什么
```

### 第 3 步：聊完手动存档（5 分钟）

每次聊完，把关键结论手动更新到你的工作日志里。

```
你可以直接让 AI 帮你总结：
"帮我总结一下今天我们做了什么，我要更新到笔记里"

然后把 AI 的总结复制到你的工作日志里。
```

### ✅ 验证：确认搭好了

1. **新对话贴入简历后，问"你知道我在做什么吗？"** → AI 应该能回答
2. **贴入工作日志后，问具体进度** → AI 应该能基于贴入的内容回答
3. **聊完后让 AI 总结** → 复制到笔记里，验证信息准确

## 三档对照：你搭好了什么

```
              🟢 满血档         🟡 半血档          🔴 手动档
核心记忆      文件自动读取      贴进设置项         每次手动贴
工作日志      AI 帮你读写       你自己维护          你自己维护
暗号路由      AI 自动响应       手动贴对应内容      手动贴对应内容
存档          AI 自动打书签     AI 提醒你手动存     你自己记得存
验证          3 步自动验证      3 步半自动验证      3 步手动验证
```

**核心方法论是一样的：** 核心记忆极简 + 单一进度源 + 按需加载。只是操作方式随工具能力调整。
